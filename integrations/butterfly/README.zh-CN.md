# 用自然语言控制 Star Arm 102

**社区 / 伙伴项目：Butterfly Community Robot Arm**

[English](README.md) · 简体中文 · [返回首页](../../README.zh.md)

通过网页描述抓放任务，由 AI 调用视觉识别、抓取规划和机械臂执行功能。项目也提供页面控制、相机标定和关节反馈。

**[查看伙伴的界面与演示](https://github.com/butterfly-community/robot-arm/blob/08498c31c56cf339601851851225bf111f89c82d/README.zh-CN.md)**

## 适用条件

- 伙伴报告已在 StarArm-102 与 RealSense D415 上完成实物抓放，其设备说明使用 RA8-U35H-M 舵机。
- 具体对应哪些 102 型号仍需确认，不能直接理解为 LD、HD、FL 全部兼容。
- 使用伙伴独立的 Docker 服务环境；自然语言任务另需兼容的模型服务。
- 支持上游的软件模拟流程，但该模式不等于包含摩擦、滑脱等现象的物理仿真。

## 如何开始

1. 阅读 [兼容性说明（英文）](compatibility.md)，核对机械臂、舵机、相机与运行环境。
2. 按 [接入步骤（英文）](setup.md) 获取对应版本，再使用上游部署文档准备环境。
3. 先检查软件模拟流程；硬件配置确认后，再进行真机连接、相机标定和第一次抓放。
4. 遇到问题时查看 [排错入口（英文）](troubleshooting.md)，记录型号、应用版本和日志。

## 版本与验证状态

本说明于 2026-10-03 核对上游提交 `08498c31c56cf339601851851225bf111f89c82d` 的资料。我们尚未完成该版本的安装、模拟运行和真机验证；这个提交是文档参考版本，不是已验证的发布版本。
