# DIY 装配

[← 硬件资源](../README.zh.md)　|　<sub>[English](README.md) / **简体中文**</sub>

如果你使用散件自行组装 Star Arm 102，请按型号选择下方的装配视频和硬件资料。机械臂已组装好？直接进入[开始使用](../../docs/getting-started.zh.md)。

| 型号 | 装配指南 | 零件与文件 |
| --- | --- | --- |
| 102-LD · 手动示教主臂 | [主体机械臂装配视频](102-ld/README.zh.md) | [BOM、STEP 与打印文件](../102-ld/README.zh.md) |
| 102-HD · 姿态保持主臂 | [主体装配与按钮接线](102-hd/README.zh.md) | [BOM、STEP 与打印文件](../102-hd/README.zh.md) |
| 102-FL · 执行从臂 | [主体与柔性夹爪装配视频](102-fl/README.zh.md) | [BOM、STEP 与打印文件](../102-fl/README.zh.md) |

102-HD 共用 LD 主体装配视频，请按 HD 指南中的说明替换舵机。FL 指南还提供了摄像头模组装配入口，该视频待上线。
