# Printing 102-FL parts

[FL hardware index](../README.md)

Printing files and validated settings are pending.

- [STL models](stl/README.md): individual printable parts for users configuring their own slicer.
- [3MF projects](3mf/README.md): projects with documented printer and slicer settings.

When publishing, include part revision, units, material, orientation, layer height, wall count, top/bottom layers, infill, and support settings. Document the slicer version, printer, and nozzle used for validation. Provide a MakerWorld link when an FL listing is available, with the same part revision as the downloadable files.

A 3MF project's settings may not transfer completely between slicers. Check the selected printer and material before slicing.
