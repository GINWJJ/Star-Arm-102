# Parts and editable models

[Hardware index and STEP descriptions](../README.md#2-open-step-files)

Start with the [102-LD BOM](Star%20Arm%20102-LD_BOM.xlsx). This folder contains editable base parts, handle/finger rings, camera mounts, and `camera.STEP`. It is not a complete assembly tutorial or a complete HD/FL parts package.

Keep originals before editing. Check screw sizes, clearances, cable routing, and camera field of view after modifying a part. See [license scope](../../LICENSE.md) before redistribution.
