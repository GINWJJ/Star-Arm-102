# Assembly documentation status

The illustrated assembly tutorial is still in preparation. This folder does not yet provide a complete, validated build sequence.

For an assembled product, begin with [hardware setup](../../docs/hardware-setup.md). For an LD parts kit, consult the [BOM and editable parts](../README.md) and [engineering drawings](../cad/README.md), and obtain the assembly instructions for your hardware revision from Fashion Star before powering the build.
